## How to represent those information?
 * Unary notation: single digits (base 1)

### Binary
* Base-2: position
* Binary digit (Bit): computer language
  * Means 0 or 1
  * Examples: 101 = 5 (1 = 4;0 = 0; 1 = 1); 1010 = 10 (1 = 8; 0 = 0; 1 = 2)
  * OBS: you can add how many bits you would like to represent any number; Add a new bit when you can't represent the number you want with the bits you already have (the new bit, in the sequence, is the number that you can't represent with the other bits)
* **Units of measure of 8 bits (byte)**
