# Problem Set 0: Galatic Unicorn 🦄💫
## Project Overview
A Scratch-base interactive game where a  flying unicorn navigates through rings to score points
## Features
- **Movement:** The unicorn follows the arrow keys to navigate the screen.
- **Dynamic Scoring:**
 - Pink Ring (Common): +1 points
 - Blue Ring (Rare): +5 points
 - Golden Ring (Legendary): +10 points
- **Audio:** Magical sound effects when collecting rings.
- **Logic:** Score tracking using a global 'Score'variable
## CS50 Requirements Met:
- At least two sprites
- At leats 3 scripts
- Use loops
- Usa conditionals
- Use variables
- Use of sound
